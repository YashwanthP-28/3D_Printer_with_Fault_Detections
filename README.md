# 3D_Printer_with_Fault_Detections
A low-cost, high-accuracy 3D printer built from scratch using Arduino Mega, RAMPS 1.4, Marlin Firmware, and second-hand components, integrated with a fine-tuned YOLOv8 model for real-time 3D print fault detection.
# 🖨️ Low-Cost 3D Printer with AI-Based Real-Time Fault Detection

A fully functional, high-accuracy 3D printer built completely from scratch for **under ₹5,000** using primarily second-hand components.

## ✨ Features

- Built completely from scratch
- High printing accuracy
- Marlin Firmware
- YOLOv8-based fault detection

## 🛠 Hardware

| Component | Description |
|-----------|-------------|
| Arduino Mega | Main Controller |
| RAMPS 1.4 | Motion Controller |
| BLTouch | Auto Bed Leveling |
